# Claire 两版卡通 3D 参考图与生成提示词

本轮交付为两张静态概念参考图，用于选定首页空间方向。使用内置 imagegen 生成，不使用 CLI/API；已有 Blender 模型、网页代码及接口未修改。开场、换盘和内容窗口仍是下一步模型与网页实现要求，静态图片不代表已经实现交互。

## 成图

- A-微缩音乐小屋.png：有厚度的圆角墙体、有限地面、三个浅展龛、墙顶立体姓名及左侧短旗串。
- B-无边音乐空间.png：连续圆弧摄影棚背景、悬挂姓名与短旗串、独立浅框和小夹子。

两版只保留星星和拼豆花两处装饰。兔子代表关于我；创作小猫代表我的作品；抱花小狗代表我的世界。总共三张盘：一张在机内，两张在展示位；第一张夹页保留正在播放标记。

## 下阶段共同交互要求

闭合播放器俯视首帧 → 盖子缓开 → 默认盘旋转 → 镜头拉远倾斜。可跳过，无自动音频播放。备用盘点击后旧盘归位、新盘进入盘仓，音符展开对应内容窗口；关闭窗口不重播开场。音乐播放与三个内容入口分别控制。

选定视觉方向后再确定静态结构、可动部件、贴图、网页文字与动画路径清单。旧 build_scene.py 的红色唱臂播放器、曲线架和单片背景不作为新版造型依据。

## 输入参考顺序

1. 参考-原音乐场景.png：主体身份与大致左右布局。
2. 参考-卡通小屋.png：卡通微缩比例与空间形状，不能照搬店铺物件。
3. 盘面-关于我.png：兔子盘原始图案。
4. 盘面-我的作品.png：创作小猫盘原始图案。
5. 盘面-我的世界.png：抱花小狗盘原始图案。
