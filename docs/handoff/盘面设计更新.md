# 盘面设计更新：优先于完整提示词中的旧盘面描述

用户最新要求：盘面不出现人像，不使用人物生活照或杂乱照片拼贴；元素精简，采用友善、简单、略不规则的小动物平面插画。介绍文字沿盘面圆周或弧线排列。仍保留三张盘各自代表的内容，不能成为只有配色不同的动物装饰盘。

- 关于我：小兔，奶油黄、珊瑚橙、叶绿；姓名、亲切问候、苹果或少量叶片，表达 Claire 的个性和自我介绍。
- 我的作品：拿笔创作的小猫，蓝色与橙色；创作路径、星星、制作／尝试／学习／成长的环绕文字，表达项目与过程。
- 我的世界：抱花的小狗，鼠尾草绿、奶油、淡珊瑚；少量花朵和音符，表达花束、手作与音乐等生活兴趣。可在后续版本用一个小拼豆花符号强化手作，不堆满装饰。

共同风格是平面印刷小动物，不是3D玩偶或写实动物；盘本身仍有真实厚度、中央孔、银色边缘和轻微反光。大量留白，每张一个主要角色和少量主题符号。例图中的英文短句为设计建议，最终文案可替换；不要以生成图文字作为不可编辑正文。

此次改动针对三张盘面。墙角、银色翻盖播放器、开场镜头、三个入口与内容窗口、主动开启音乐等既定设计保留。
