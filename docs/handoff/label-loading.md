# 唱片盖标签加载入场

刷新时复用原始标签的矢量名字和星标，去掉加载阶段的纸张底色，单独显示在首帧标签的屏幕投影位置。计算位置前隐藏，防止脚本尚未执行时图片在默认位置闪现。中心和倾斜角度固定，初始放大 1.45–2.2 倍，加粗的珊瑚色胶囊形轮廓显示资源准备进度。下载进度占前 70%，模型附属资源至 85%，渲染准备至 95%，首帧着色器编译完成后才到 100%。

进度条用保留速度的高阻尼弹簧跟随进度，起步轻快、中段稍缓、末端柔和追上，始终向前。至少用 1.2 秒完整走一圈，弹簧收尾允许略长；若实际资源较慢，则随实际进度等待，就绪后补完剩余轮廓。完成后保留整圈 150ms，再以 480ms 无回弹缓动缩回真实大小；200ms 时唱片机开始淡入，最后 100ms 标签与模型原始印刷标签交接，然后播放现有开场。桌面刷新再次播放，手机交接后进入静态首页。减少动态效果跳过进度条刻意延时，用 160ms 淡出替代缩放。跳过在加载、完成停顿和交接阶段均立即响应；加载失败仍可浏览内容。

`src/loading-label.json` 是原始标签网格、首帧相机和闭合盖子姿态导出的投影数据。模型首帧或标签几何改变后，用 `node tools/extract-loading-label.cjs` 更新它和 `assets/loading-label.svg`，再执行 `npm run build`。

验证：`node tools/label-loader-check.cjs`，默认预览端口 4198，可设置 `CLAIRE_BASE_URL`。现有回归测试用 `CLAIRE_CHECK_DIR` 指向新证据目录，保留原始验证文件。
