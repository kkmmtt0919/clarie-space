# Claire · 交互与文字精进方案 v3

更新：2026-10-05。状态：设计审阅稿，等待用户看过后再修改源码或模型。

本稿延续银灰无边空间、磨砂翻盖播放器、镜面镭射光盘与三个紧密错位夹页。重点是入场镜头与唱片悬停，其次是排版和文字。本文数值均为拟定起点，尚未通过动画预览验证；不表示已经实现。

本稿优先于《设计说明与生成提示词》中的旧动效参数；其他模型结构与内容规则继续沿用。当前 Blender 模型与运行时保持原样。旧《完整网页提示词》的墙角、动物贴纸、暖色房间与字体要求属于历史方向，不能作为本轮实现依据。

## 1. 设计判断：物件有分量，交互有弹性

体验像打开一台自己的播放器，再从收藏里抽出一张想看的盘。银色机身负责真实感，少量印刷拼贴负责个性，指针反馈负责轻快。镜头从容、盖子有机械重量、夹页轻快回弹，三者采用不同运动性格。

悬停的目的，是告诉访客“这一张可以选”，并露出更多图案。入场的目的，是建立播放器与三个入口的空间关系。文字的目的，是说明怎么逛、哪里有内容、声音是否开启。

| Before | After | Why |
| --- | --- | --- |
| 开盖和镜头都用泛称“柔和缓动” | 开盖先轻启再展开；镜头一段连续拉远倾斜，末段长减速 | 各动作有重量与主次，避免所有物件同速移动 |
| 悬停约 300ms、退出约 350ms，无弹性定义 | 立即响应、一次小幅越界回弹；约 220–280ms 已能清楚辨认目标，随后快速收稳 | 更 Q 弹，同时保持选择效率 |
| 切换目标重新开始缓动 | 从当前位置与当前速度转向下一目标 | 快速划过三张时连贯，不突然刹车 |
| 非目标卡片后退或降亮度 | 默认保持其他两张位置和亮度，仅当前目标突出 | 避免整组躁动，让其他标题持续可读 |
| 键盘焦点使用同样突出动画 | 焦点立即显示清楚描边／标题强调，省略弹跳 | 键盘导航直接、稳定 |
| 音符 0.4–0.7 秒展开窗口 | 一笔短弧引导后，面板约 220–280ms 出现 | 保留音乐隐喻，减少等待正文的时间 |

## 3. 入场镜头：4.2 秒的一镜到底

继续保留“闭盖俯视 → 开盖露盘 → 拉远倾斜至完整场景”。首次加载资源就绪后播放一次；跳过入口从首帧可用。关闭内容窗口不重播。下表是网页目标节奏，Blender 后续按 30fps 转译，并重新安排演示段落，不能直接挤压现有换盘关键帧。

| 时间 | 主角 | 画面与动作 | 节奏与画面检查 |
| --- | --- | --- | --- |
| 0.00–0.30s | 闭合播放器 | 稳定近距离俯视，外壳轮廓完整，姓名贴纸可见 | 给访客一个明确首帧，避免长时间等动作 |
| 0.30–0.65s | 盖子 | 铰链轻启至约 8–12°，镜头维持近景 | 一次短促启盖，随后进入连续展开；不配自动声音 |
| 0.65–1.85s | 盖子与露出的盘 | 盖子展开至约 78°，后半程明显减速；镜头开始很小的倾斜 | 像实物翻盖，有重量，不撞到终点也不弹两次 |
| 1.35–2.10s | 默认盘 | 盘面露出后才开始轻微加速，反光随转动改变 | 不让镜头、盖子、盘同时争夺注意力；轴心固定 |
| 1.65–3.80s | 整体空间 | 镜头连续拉远、降低俯视角，逐渐露出三套夹页 | 用强 ease-in-out 起步与减速；机身到卡组形成清楚视线接力 |
| 3.80–4.20s | 三个内容入口 | 镜头收稳；一行选择提示淡入，音乐控制可用 | 文案约 160–180ms 淡入；卡组不做自动轮流弹跳 |

镜头不超越最终机位再反弹，不做呼吸缩放、连续摇摆或突然切镜。位置、朝向与正交缩放共用同一进度，以免拉远和转向分离。建议方向用四元数插值，取景锚点从播放器中心平滑转到播放器与卡组之间；盖子运动和相机路径需逐帧检查裁切、遮挡与穿模。

最终机位继续沿用现有整体构图，首帧沿用闭盖俯视。镜头曲线建议以 `cubic-bezier(0.77, 0, 0.175, 1)` 为起点；启盖使用明确的 ease-out，展开末段加强减速。曲线需经实际预览调整，不能仅凭参数认定自然。

跳过开场：立即落到完整场景、盖子打开、默认盘就位，取消未完成动画，提示立即可读。减少动态效果与再次进入首页：直接显示最终状态。移动端默认采用最终机位，不强制播放长开场，可提供主动“看看开场”入口。

## 4. 三个唱片入口：抽出一点，再轻轻收住

### 静止与悬停终点

保持三套夹页紧密、斜向、近似平行叠放；相邻投影重叠约 30–40%，三个名称都露出。悬停终点先沿用现有空间幅度：朝镜头前移约 0.12 卡宽、抬高约 0.07 卡高、放大至 1.03 倍，朝更正面方向转约 4–6°。比起加大位移，优先改善起步、惯性和收尾。

选中夹页与夹页内的备用盘作为一个视觉组移动。当前盘已在机内时，仅夹页突出，盘仓中的盘保持原位。“正在播放”始终跟随当前内容盘，不能跟随悬停。

### Q 弹的形状

指针移入即开始移动，没有额外等待。约前 80–120ms 已有明显抽出反馈，约 220–280ms 目标清楚可选；越过目标一次，再快速回到终点，视觉收稳目标约 350–450ms。收稳时间不阻塞点击。

回弹越界以总位移的 5–9% 为起点；1.03 的终点缩放峰值约为 1.032–1.033，不放大到 1.1。卡片保持硬纸物件，不做橡皮式拉长、挤压或多轮振荡。位置、转角和缩放使用同一弹簧进度，避免盘与夹页各弹各的。

拟定物理起点：质量 1、刚度 500、阻尼 32。该配置预计只有一次轻微过冲，实际峰值、收稳速度和卡片间距需预览测量。参数可调整，但须保留“即时起步、一次小回弹、快速稳定”的可观察行为。不能把“约 250ms 的明显反馈”写成“250ms 内物理弹簧必定完全停止”。

### 快速切换和离开

从关于我快速划到作品、世界时，各组从当前位置及当前速度转向目标；不重置到静止位置，也不每次从零速度启动。旧目标回落、新目标抽出，其他两组不统一退后、不集体摇摆。

离开卡组时更利落地收回，阻尼可提高到约 40，目标是约 200–280ms 基本归位，避免退出拖沓和明显二次反弹。选择区域使用静止布局的稳定命中面，并容纳选中物件移出后的可见区域；遮挡改变不能反复触发移入移出。移动到另一张原始可选区域，应优先选中那一张，不能被前一张弹出的卡吞掉命中。

点击不必等弹簧结束：从当下姿态接入选择动作，先交接该对象的动画控制，再执行换盘。换盘期间暂停悬停控制；窗口打开时背景入口不接收悬停。连续点击只保留最后一个待选目标，防止重复换盘。

### 其他输入方式

键盘：Tab 立即显示清楚焦点描边与入口名称强调，Enter／Space 确认；不为每次焦点移动播放弹跳。关闭内容后焦点回到触发入口。

触屏：单次点击直接选择，不要求第一次点悬停、第二次点确认；按下反馈可缩到 0.97，约 100–140ms，随后进入选择流程。提供清楚文字入口，不能依赖细小三维露出面。

减少动态效果：取消相机移动、空间抽出、回弹、盘的持续旋转和取盘飞行；用清楚焦点、静态状态替换与短淡入表达选择。入口名称、当前内容盘与声音状态仍可辨认。

## 5. 视觉与文字：让收藏有自己的语气

### 印刷与排版

播放器保留冷白、银灰、黑色与真实金属反光；纸感和扫描肌理仅出现在盘面印刷、夹页与内容里的图片局部。正文背景保持干净。每张夹页一处主视觉、一处编号、一句可选短注，最多一笔黑色箭头或星号。

三张盘共用清楚的编号系统：01 朱红、02 钴蓝、03 酸绿；每张以自己的点缀色为主。镭射反光来自材质，不在页面上额外铺彩虹渐变。短注可轻微倾斜、不齐基线；入口标题、正文和按钮使用清楚字体，中文不故意写坏。英文档案小字是次级信息，不能把关键提示做成读不清的微型字。

网页正文建议 16–18px，辅助操作不小于 14px，正文行高约 1.6；字号是 CSS 像素，不套用宣传片的 1080p 像素规则。艺术贴图里的装饰文字与网页控件分别处理，入口始终有真实可访问名称。

### 文案草案

以下是本轮原创候选文案，供审阅。只表达浏览语气，不补写未经确认的个人经历、作品成绩或歌单。

| 位置 | 建议文字 | 用意 |
| --- | --- | --- |
| 首页姓名旁短句 | 做一点东西，也收藏一点日常。 | 把作品和生活串起来，保持轻松 |
| 桌面卡组提示 | 移过去看看，点一下打开。 | 说明悬停与点击的区别 |
| 触屏入口提示 | 选一张，打开看看。 | 与单次点击行为一致 |
| 01 主标题／短注 | 关于我／一些关于 Claire 的线索。 | 留出介绍空间，不自夸 |
| 02 主标题／短注 | 我的作品／做过的，也在继续试。 | 给成品与过程共同的位置 |
| 03 主标题／短注 | 我的世界／音乐、手作，还有日常。 | 呼应已确认的兴趣方向 |
| 内容盘状态 | 当前内容：关于我 | 避免把内容盘误认为正在出声 |
| 盘面艺术标签 | 正在播放 · 关于我 | 作为播放器隐喻；音频控制另有明确状态 |
| 声音入口 | 开启音乐 | 明确需要访客主动操作 |
| 声音未启用 | 声音未开启 | 说明旋转不等于已经播放音频 |
| 声音已暂停 | 音乐已暂停 | 与内容选择状态分开 |
| 开场操作 | 跳过开场 | 首帧即可使用 |
| 内容关闭操作 | 回到唱片 | 清楚表达返回场景 |

盘面可选英文短注为 `ABOUT / MADE & MAKING / OFF DUTY`，只作低密度印刷细节，不重复整段中文，也不放伪造日期、收藏编号或真实曲目。短句不逐字打出、不随悬停整段重新播放。

内容窗口采用轻薄暖白面板、黑色正文、与入口匹配的一处颜色标记。作品页面重点展示一件作品与其过程；世界页面允许更自由的图文拼贴。窗口进入可从 0.97 缩放至 1 并淡入，约 220–280ms；退出约 160–200ms。保留音乐隐喻的一笔短弧或少量音符，但不增加漫长粒子演出。

## 6. 审阅后再实施的顺序

1. 先确认本稿的整体语气、4.2 秒开场节奏、一次小回弹和文案候选。
2. 再修改 Blender 入场与悬停预览，保持现有几何、贴图和三盘数量；将同一回弹语言同步到时间线演示，避免实时预览与演示不一致。
3. 查看开场关键帧与短动画，检查盖子开合、镜头构图、三张标题可见性、回弹峰值和快速切换。参数依实际观感修订。
4. 网页项目确定后再迁移动效与交互状态，补齐键盘、触屏、减少动态效果、跳过开场和内容窗口，不把 Blender 预览称为网页交付。

审阅重点：开场是否从容但不拖；Q 弹是否只出现一次且有纸卡的分量；三个标题在所有状态是否能读；快速划过是否连续；音乐状态是否清楚；短句是否像 Claire 自己会说的话。

本轮交付只有技能安装与设计文档更新，未修改 `.py`、`.blend`、网页源码或现有贴图，也未生成新的效果图或动画预览。
