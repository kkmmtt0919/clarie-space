# 唱片机首页封面 · 3D 化设计规范

> 目标：为「个人网站首页封面」确立一套**可直接交付建模**的唱片机方案。
> 风格基调：复古童书 / 昭和画报气质 —— 米白做旧纸感、低饱和玫瑰红 + 灰蓝 + 鼠尾草绿 + 芥末黄。
> 关键约束：**物品本身必须呈现真实的 3D 体积与材质；油画质感只允许出现在背景。**

---

## 一、整体布局与空间关系

### 1.1 三区制布局（俯视）

以圆形木质地台为统一承载面，物品按「**播放区 · 收纳区 · 展示区**」三区分布，形成稳定的三角构图：

| 区域 | 位置（俯视） | 内容 | 作用 |
|---|---|---|---|
| **A 播放区** | 中偏后（视觉中心） | 开盖唱片机主体 + 唱盘 + 唱臂 | 舞台主角，视觉焦点 |
| **B 收纳区** | 左后方，呈 30° 斜向 | 8 槽垂直唱片架 | 整齐有序的收纳/取用，体现「可选」 |
| **C 展示区** | 右前方 | 独立展示托架 + 当前唱片 | 「Now Playing」的仪式感 |

- 三区之间保留 40–60mm 净空（视觉与建模上都需要，避免部件相接）。
- 地台为直径约 720mm 的圆木盘，边缘 8mm 倒角，所有物品脚底必须落在同一标高 Z=0 上。
- 收纳区刻意留 2 个**空槽位** —— 这是"唱片被取走了"的叙事线索，直接表达"可更换"。

### 1.2 Z 轴分层（景深结构）

| 层 | 内容 | 处理方式 |
|---|---|---|
| L0 | 油画背景（远） | 明显笔触堆叠、低饱和、边缘暗角、轻微虚化 |
| L1 | 木质地台 | 承接所有物品，提供接触阴影 |
| L2 | 唱片机主体 / 收纳架 / 展示托架 | 同一标高，实体建模主层 |
| L3 | 盖子（动态） + 唱臂 + 唱片 | 唯一有运动逻辑的层 |
| L4 | 前景浮尘 / 飘散音符粒子 | 极弱，仅强化纵深，不参与结构 |

### 1.3 真实尺寸基准（建模交接）

| 部件 | 尺寸 |
|---|---|
| 唱片机机身 | 320 × 320 × 150 mm |
| 盖子开启角度 | 105°（自水平面起算） |
| 12 寸唱片 | ⌀305 mm，厚 3 mm |
| 唱片封套 | 315 × 315 × 5 mm |
| 收纳架 | 340 × 130 × 320 mm，8 槽，槽间距 42 mm，后倾 15° |
| 展示托架 | ⌀200 mm 底座，唱片倾角 70° |
| 地台 | ⌀720 mm，厚 24 mm |

## 二、唱片的三种状态与更换机制

这是整套方案的核心逻辑。唱片被明确定义为**三个可独立建模/独立动画的状态**：

| 状态 | 位置 | 朝向 | 建模要点 |
|---|---|---|---|
| **① 收纳态 Stored** | 唱片架槽位内 | 垂直立起，后倾 15°，仅露出侧边与部分 label | 需显露 3mm 碟身厚度与沟槽侧壁 |
| **② 播放态 Playing** | 唱片机唱盘上 | 水平，绕中心轴旋转 | 中心孔与轴心需做真实配合公差 |
| **③ 展示态 Showcased** | 前方独立托架 | 倾斜 70° 面向观众，被一束柔光单独照亮 | 需正反两面材质区分（A 面 label / B 面沟槽） |

### 2.1 更换动线（取 → 移 → 落 → 归）

```
抽出 (+Y 30mm)  →  上提 (+Z 60mm)  →  平移至唱盘上方  →  对轴下落 (-Z)  →  空槽留白
```

- **抽出**：沿槽位前向 Y 轴平移，毛毡内衬提供阻尼感（摩擦系数高，避免滑落）。
- **上提**：垂直抬升，脱离槽壁高度（槽深 = 唱片直径的 34%，约 104mm）。
- **对轴下落**：唱盘中心轴（⌀8mm 中心轴）与唱片中心孔（⌀7.4mm）需保留间隙，建模时不得无缝贴合。

### 2.2 收纳区的"整齐有序"如何实现

- **等距槽位**：8 个槽严格等距 42mm，槽壁与唱片之间单侧留 3mm 间隙。
- **统一后倾角**：全部唱片 15° 后倾，形成一条干净的斜线，这是"秩序感"的来源。
- **半圆托底**：每个槽底部有半圆形托弧（半径 ≈ 152mm），承托唱片下沿，不靠碟身摩擦站立。
- **侧向导轨**：槽壁内侧 2mm 毛毡条，兼作导轨与防刮层。
- **标签朝外**：所有 label 朝向观众一侧，颜色各异 —— 视觉上"每张都不一样"，强化可换感。

## 三、3D 质感的具体表现要求

### 3.1 体积感（Volume）

- **一票否决项**：任何物件不得出现零厚度面片。唱片 3mm、封套 5mm、盖板 8mm，全部要有实体厚度。
- **倒角是体积感的来源**：机身棱边 3mm 倒角，盖子边缘 2mm 倒角，旋钮边缘 R2 圆角。倒角处产生的**高光窄边**是"这东西是实心的"最直接证据。
- **可见的层级断面**：盖子打开后，要能同时看到外侧木壳、内侧绒布基底、包边三条不同的面 —— 立体层次靠"断面信息量"堆出来。

### 3.2 材质分区表（建模直接可用）

| 部件 | 材质 | 关键参数 |
|---|---|---|
| 机身外壳 | 胡桃木，哑光 | Roughness 0.55–0.65，木纹沿长边走向，纹理需贴图非程序化噪点 |
| 盖子内衬 | 米色呢绒 / 绒布 | Roughness 0.9，需有绒毛法线，颜色略深于背景米白 |
| 唱盘垫 | 黑色橡胶 | Roughness 0.85，环状纹理 |
| 中心轴 / 唱臂 | 拉丝黄铜 + 镀铬 | Metalness 0.9，Roughness 0.25–0.35，与木质形成高反差 |
| 唱臂配重 / 唱头 | 深色电木 + 玫瑰红漆点 | 半光，Roughness 0.3 |
| 黑胶唱片 | 半光黑胶 | Roughness 0.28，沟槽用**法线贴图**表现，不做几何细环（除特写） |
| 唱片 label | 哑光纸 | Roughness 0.8，四色：玫瑰红 / 灰蓝 / 鼠尾草绿 / 芥末黄 |
| 旋钮 / 摇柄 | 玫瑰红电木 | Roughness 0.3，高光锐利，作为画面唯一"亮色锚点" |
| 唱片架 | 木质（比机身深一号） | 槽内 2mm 毛毡条，Roughness 0.85 |
| 展示托架底座 | 暗玫瑰丝绒 + 黄铜环边 | 丝绒 Roughness 0.9，黄铜环 Metalness 0.9 |
| 地台 | 浅色桦木 | Roughness 0.6，中央略亮形成自然聚光 |

**材质总原则**：全画面只用**两种肌理语言** —— 木头/绒布（粗糙、无高光）与 金属/电木（光滑、有高光）。靠这两极的对比产生立体层次，不靠色彩堆叠。

### 3.3 光影要求

- **主光**：左上 45° 暖光，色温 3200K，作为唯一投射硬边的光源，负责所有主要高光与阴影。
- **补光**：右侧弱冷光，5600K，强度约主光 25%，只负责把暗部从死黑里拉回来（保证 3D 渲染的受光面可读）。
- **底反弹光**：极弱，防止物体底部与地台"糊"在一起。
- **接触阴影（必须）**：每个物件与地台之间必须有柔和接触阴影，半径小、衰减快。**没有接触阴影，物体就是"飘"的**，这是最容易暴露"2D 拼贴感"的地方。
- **展示位聚光**：展示托架上的唱片额外获得一束柔和顶光，形成一块亮区 —— 这是全画面唯一的"舞台光"。
- **阴影质感**：柔和（大半径、低密度），不用硬边投影，保持童书的温柔感。

### 3.4 立体层次（深度线索）

按「近实远虚」三层衰减，这是让平面构图产生纵深的唯一手段：

| 层次 | 饱和度 | 对比度 | 清晰度 |
|---|---|---|---|
| 近景（展示托架） | 100% | 100% | 全清晰 |
| 中景（唱片机主体 + 收纳架） | 95% | 95% | 全清晰 |
| 远景（油画背景） | 60% | 70% | 明显虚化 |

### 3.5 油画背景的处理边界

**可以**：
- 背景整块使用油画质感：明显可见的笔触堆叠、颜料厚度感、画布纹理。
- 背景做上下分层：下方为油画地面（暖米色），上方为油画墙面/天空（灰蓝），形成"舞台式"空间。
- 边缘暗角，把视线往中心收。
- 物品轮廓外可保留 1–2px 的细手绘描边，用来与童书风格衔接。

**不可以**：
- 物品表面不得出现笔触、颜料堆叠、涂抹感 —— 表面必须是干净的 3D 渲染面（清晰的法线朝向、可读的反射）。
- 不得用"手绘明暗"代替真实光照。物品的明暗必须由光源位置决定，而不是"画上去"。
- 不得给物品加纸张颗粒/做旧噪点（那会破坏材质辨识度，也会让模型导出后对不上）。

**一句话原则**：**背景是画出来的，物品是造出来的。**

## 四、建模交接要点

- **分件命名建议**：`body` / `lid_hinge` / `lid_panel` / `platter` / `platter_mat` / `spindle` / `tonearm_base` / `tonearm_arm` / `counterweight` / `cartridge` / `knob_L` / `knob_R` / `crank` / `rack_frame` / `rack_slot_01–08` / `record_A–H` / `plinth_base` / `plinth_ring` / `platform`
- **拓扑**：圆柱类部件（唱盘、唱片、旋钮、底座）分段数 64 起；机身建议布尔运算后重拓扑，倒角用实体倒角而非平滑组，否则近景会穿帮。
- **层级关系**：`lid_panel` 挂载在 `lid_hinge` 下（旋转轴），`platter` 挂在机身下（自转轴），`record` 独立于 `platter`（便于更换动画）。
- **动画预设**：`lid` 开合 0°→105°；`record` 沿"抽出→上提→平移→下落"四段曲线运动；`tonearm` 从停靠位摆动到播放位。

## 六、本轮修订：CLAIRE 首页真实 3D 空间与无重叠交互

> 本节为针对当前首页截图的最新修订；与前文冲突时以本节为准。前文木质地台、8 槽收纳架、油画背景与黑胶材质保留为其他方案参考，本轮不应用。保留当前米白背景、银灰开盖唱片机、虹彩唱片和三个内容入口。本轮只修正空间、物体体积、布局与交互。

### 6.1 核心空间约束

- 使用共享相机、共享灯光、共享地面的真实 3D 场景。唱片是有正面、背面、侧壁、中心孔的薄圆柱实体，封套是有厚度的实体；不能把圆形图片或 DOM 卡片旋转后当作完整模型。
- 统一坐标：X 为左右，Y 为上下，Z 为前后，相机从 +Z 看向场景；地面为 Y=0。近景唱片机、中景展示唱片、远景封套通过 Z 距离、朝向、透视、受光面和投影建立层次，不能依赖物体遮挡来表现纵深。
- 两张待选唱片分别占用右侧两个独立展示位，横向分开，前后略错位。三个封套进入独立陈列位，取消截图中的阶梯叠放。唱片与所属封套也分开摆放，以编号、颜色和位置建立对应关系，不遮挡封套标题。空间不足时改为两行或纵向排布。
- “空间不穿透”和“画面不重叠”同时成立：不同展示位的唱片、封套、唱片机与标签，其投影到屏幕上的可见轮廓不得相交。唱片装入唱盘、托架承托等必要装配关系除外；阴影允许自然交汇，但不能形成一整块灰色剪影。
- 基准视口 1440×960；独立展示物轮廓净距至少 32px，交互动画全过程至少 24px。用投影包围盒作为保守检测，并预留悬停位移、标签和相机视差余量；仅调整 z-index 或 Z 坐标不能算修复。
- 空间不足时依次减小物体尺寸、扩大布局间距、调整相机距离、切换分行布局。不得牺牲可读性或用重叠挤进首屏；小屏允许页面向下延伸。

### 6.2 可直接使用的提示词：状态 + 触发 + 反馈 + 参数

请修改当前 CLAIRE 个人网站首页。保留米白背景、现有文案与导航、银灰开盖唱片机、虹彩唱片，以及“关于我 / 我的作品 / 我的世界”三个内容入口。当前右侧唱片和封套重叠，物体像平面素材拼贴；请重建共享相机与灯光的真实 3D 空间，并落实下列状态机。前后层次通过真实空间与光照体现，每个可选物件在屏幕上完整、独立可见。

#### 状态 1：默认陈列
- 状态：唱片机在左侧近景；两张待选唱片在右侧两个独立展示位，位置一前一后但屏幕轮廓分离；三个封套各自独立可读。唱片有细小支架承托，底部与统一地面产生接触阴影。
- 触发：首次加载完成、关闭内容、鼠标离开交互物件。
- 反馈：呈现有厚度、有侧面、有透视的稳定陈列。虹彩随法线和观察方向变化；唱片侧缘高光、中心孔内壁和背面材质可读。阴影与物体位置一致。
- 参数：唱片直径为场景单位 D，厚度 0.008D–0.012D；封套厚度 0.015D；默认唱片绕 Y 轴偏转 12°–20°，绕 X 轴倾斜 4°–8°。两个展示位 Z 差初值 0.35D–0.60D，最终以投影净距为准。透视相机垂直 FOV 30°–38°，适度俯视 10°–15°。1440px 宽视口唱片投影直径初值 150–180px；陈列轮廓净距 ≥32px。左上大型面光源、右侧弱补光约为主光 20%–25%；唱片表面 roughness 初值 0.25–0.35。参数为调试初值，不替代画面验收。

#### 状态 2：悬停 / 键盘聚焦
- 状态：只激活当前唱片，其余物件保持陈列位置。
- 触发：鼠标进入唱片命中区域，或键盘 Tab 聚焦对应入口。
- 反馈：唱片轻微抬起、向观察者靠近、转向用户；支架仍留在原位，阴影随高度变淡、变软；独立留白区域显示名称和“点击打开”。不能放大后压住邻近唱片或封套。
- 参数：上移 0.04D–0.06D，前移最多 0.06D，转向幅度 ≤6°，缩放 ≤1.02；过渡 220–280ms，ease-out。按完整动画包围范围保留 ≥24px 净距；若间距不足，自动减小位移与缩放。标签距物件 ≥12px，避开其他标题。

#### 状态 3：打开内容 / 换片
- 状态：进入 switching，当前只有一张唱片执行更换，目标唱片尚未播放。
- 触发：点击唱片、按 Enter，或点击对应导航。
- 反馈：先停转，将旧唱片沿独立回程退回空闲展示位，再让目标唱片沿预留通道移到唱盘上方，转为水平、对齐轴心后下落。唱片落稳才更新“当前内容”并打开对应内容面板。不要穿过机盖、其他唱片、封套或标签；目标展示位暂时留空，不复制同一张唱片。音频仅在用户主动开启后播放。
- 参数：总时长 900–1200ms，先退片再进片，禁止两张唱片同时经过唱盘；按旧片抬起、归位、目标片移动、下落分段编排。唱片越过机身时底缘高于路径内障碍最高点至少 0.08D。规划并逐帧检查投影净距 ≥24px；落入唱盘时仅豁免与唱盘的装配遮挡。相机保持稳定；动画期间合并重复输入为最后一次选择，当前过渡完成后再执行。

#### 状态 4：播放 / 内容已打开
- 状态：选中唱片位于唱盘，相关内容已打开；该唱片原展示位为空，其他待选唱片仍各自独立。
- 触发：换片动画完成。
- 反馈：显示唯一“当前内容 / 已选中”标记。用户开启音频后显示“正在播放”，唱片绕自身法线连续旋转；音频关闭或暂停时停止。关闭内容返回首页，保留当前选择和明确的音频状态。
- 参数：旋转初值每圈 8–12s，恒速；旋转只作用于唱片网格，不带动支架、标签或封套。暂停减速 250–400ms；状态标记放在独立文字区域，不压住唱片表面。

#### 状态 5：窗口变化 / 触屏 / 减少动态效果
- 状态：保持物件独立可见，根据可用区域重新排列。
- 触发：窗口缩放、设备横竖屏切换、触屏输入，或 prefers-reduced-motion 开启。
- 反馈：宽屏采用左唱片机、右独立陈列；空间不足时右侧改为两行，小屏改为唱片机在上、选择区在下。触屏直接点选，无需先 hover。减少动态效果时省略搬运与连续旋转，用短暂淡入淡出更新状态。
- 参数：断点初值 1200px 与 900px，最终按投影包围范围决定；中小屏物件净距 ≥20px，触控目标 ≥44×44px。减少动态效果过渡 ≤150ms。禁止通过裁切、负间距或叠放解决空间不足。

### 6.3 验收标准

1. 默认、悬停、聚焦、换片及窗口缩放过程中，不同陈列物件的可见轮廓不相交；标题与标签不遮挡。
2. 唱片有可辨认的侧壁、厚度与孔内壁，角度变化后反射和受光面同步变化；不能只有正面贴图在缩放。
3. 前后物件处于不同深度，但各自完整可见；接触阴影与移动阴影符合统一光源和地面。
4. 任意时刻每张唱片只存在一个实例，当前选择标记唯一；展示位与装载状态一致。
5. 至少核对 1440×960、1280×800、1024×768、390×844，以及两张待选唱片分别悬停、快速连续切换的状态。提交同机位默认与悬停截图、侧面体积截图和换片短录屏，作为实现验收证据。

## 七、录屏反馈修订：柔和开场、取消轨迹线、进入内容后的换片归位

> 本节依据用户提供的 `20261006-0547-22.9796072.mp4` 与三项主观反馈修订。与第六节冲突时，本节在开场、换片时长、往返内容后的状态恢复方面优先；第六节的真实 3D、屏幕不重叠和响应式要求继续有效。本次修改交互规范与提示词，网页及模型尚未修改、复测。

### 7.1 感受与修改目标

1. **开场开盖生硬：**用户需要看清盖子慢慢打开，再让镜头旋转。建立“安静起势 → 开盖 → 停留 → 转镜头 → 稳定陈列”的连续节奏。不要只把整段录制播放变慢，盖子与镜头需要分段控制。
2. **换片中间出现一条线：**取消换片的蓝色可见轨迹，保持物件自身运动与阴影反馈。当前 HTML 有 `svg.selection-arc`，CSS 在 `.stage.swapping` 时显示并绘制该路径；这是可以移除的视觉层。内部移动路径仍需保留。
3. **点进内容一次后，再次换片会穿模、偏离原来的层级：**用户期待每张唱片始终有自己的原位，进入内容并返回不会改变空间秩序。录屏约 4.8s、10.6s 的采样画面可见唱片与机身前缘相交。源码换片路径包含低位前方节点，需要结合唱片完整体积检查；仅凭录屏尚不能断定进入内容后异常的唯一代码原因，坐标、父节点、动画状态恢复也需排查。

### 7.2 可直接交付的修改提示词

请继续修改当前 CLAIRE 唱片机首页。保留现有视觉与内容，继续满足真实 3D 体积、前后层次及独立展示物不重叠的要求。重点处理以下三个体验问题，并按“状态 + 触发 + 反馈 + 参数”实现。不要只验证首次换片；必须验证进入内容、返回首页之后的连续切换。

#### 一、开场：先慢慢打开盖子，再旋转镜头

- **状态：**`opening-lid` → `lid-settled` → `camera-reveal` → `idle`。盖子由关闭姿态逐渐到达现有模型的正常开启角度；镜头在开盖期间固定，开盖完成后才转向最终首页机位。
- **触发：**首次进入首页或点击“再看一次开场”。首次进入与重播使用同一时间线。重播前先恢复本次开场的规范初始状态，避免从上一次换片残留姿态开始。
- **反馈：**盖子起步缓慢，中段自然加速，接近终点时柔和减速，像带阻尼的实体铰链。开盖后短暂停留，让用户看清内侧与盘仓；随后镜头平稳旋转到首页构图，逐渐停稳。动作衔接自然，盖子不弹跳，镜头不突然切换，盖子与机身保持真实连接。
- **参数：**起始停留 200–300ms；开盖 1800–2200ms；开盖完成后停留 200–300ms；镜头旋转 1200–1600ms。建议起始版本为 250 + 2000 + 250 + 1400 = 3900ms。开盖、镜头分别使用端点速度为零的缓入缓出曲线，例如 `smootherstep`；盖子绕真实铰链轴旋转至模型既定开角，不超调。镜头通过连续轨道移动并保持观察目标稳定，旋转幅度初值 15°–25°；整个过程保留完整机盖和机身，不裁切主体。最终姿态直接作为静态首页姿态，避免结束时二次跳位。
- **补充约束：**减少动态效果时直接呈现最终首页；跳过开场应一次性落到一致的最终姿态并取消旧动画。开场过程中不叠加悬停、换片或第二条开场时间线。若当前设备占比不适合这些角度，以最终构图和无碰撞为准调整。

#### 二、换片：取消中间的可见线条

- **状态：**`switching`，旧唱片退回、目标唱片装载。
- **触发：**点击另一张唱片、对应导航，或键盘选择其他入口。
- **反馈：**用户只看到唱片实体沿清楚、自然的路径移动，阴影随位置与高度改变。画面中不出现蓝色弧线、连接线、虚线、拖尾或调试路径。选择完成后的编号和内容状态提供确认。
- **参数：**可见轨迹对象数量为 0，覆盖首次切换、再次切换、连续快速切换与重播后的切换。移除 `svg.selection-arc` 及其绘制动画，清理相关视觉引用；如存在 3D 曲线辅助对象，也不加入用户场景。内部路径控制点与避障逻辑照常工作。保留页面原有的常规导航与分隔线。

#### 三、进入内容后再换片：固定原位，完整避障

- **状态：**每张唱片有固定编号、固定原位和明确状态：`stored`、`returning`、`loading`、`on-player`。三张唱片各只有一个实例；只有当前唱片在唱盘上。内容面板的打开、关闭不改变唱片所在状态、模型父节点或展示位坐标。
- **触发：**首次换片；进入任何内容后关闭并选择另一张；用关闭按钮、Esc 或点背景返回；快速连续选择；选择当前唱片；换片后再次重播开场。
- **反馈：**旧唱片先垂直离开盘仓，沿预留通道回到自己的编号展示位，恢复原来的位置、朝向和尺寸；目标唱片再从自己的展示位取出，移到唱盘上方，转为水平，对齐轴心后垂直落下。它不会擦过机身前缘、穿过打开的盖子、封套或其他唱片。打开内容再返回后，唱片的前后位置与操作前一致；连续切换不会越换越偏。点击当前唱片直接打开对应内容，不重复搬运。
- **参数：**完整换片初值 2200–2800ms，旧片归位 1100–1400ms，目标片装载 1100–1400ms；具体速度以避障与顺畅为准。取消低位穿过机身前缘的路径：先抬升，再横移，最后下落。路径全程以唱片外缘、厚度和旋转后的完整体积检查，不能只检查圆心；与非装配物件的最小实体间隙初值 ≥0.08D，D 为唱片直径。独立展示物之间的屏幕净距仍 ≥24px；装入唱盘的必要装配遮挡除外。换片时相机保持最终首页机位，不增加拉远再拉近的呼吸动作。
- **归位规则：**为每张唱片保存独立的、由当前布局确定的展示锚点，包含位置、朝向、尺寸；唱盘也有独立锚点。不要把移动中的当前坐标或悬停位移覆盖为新原位。每次换片从当前实际姿态连续起步，以规范锚点精确结束。窗口变化时重新计算整套布局锚点，不能累积偏移。
- **坐标与层级规则：**移动起点、路径控制点和终点必须在同一个坐标空间计算。建议唱片移动根节点始终挂在同一个场景父节点下；如必须换父节点，保持切换瞬间的世界变换，并将后续路径转换到新父节点坐标。保持真实深度测试与正常遮挡关系。旋转盘面单独控制，不与换片路径争抢同一个变换。
- **动画恢复规则：**进入换片时冻结悬停和自动旋转，避免多个动画同时改写位置、朝向或缩放；完成后明确设置旧片展示姿态与新片装载姿态，再恢复允许的交互。内容关闭仅恢复交互和焦点，不重置世界姿态。动画期间保留最后一次有效选择，当前归位完成后再执行；取消或跳过时清理旧回调并落到完整一致的状态。

### 7.3 必须覆盖的验收过程

- **开场节奏：**从首次进入与点击重播分别录制；开盖阶段镜头保持固定，盖子慢开慢停；短暂停留后镜头才开始旋转，最后停在同一个首页机位。
- **轨迹线：**逐段检查完整换片录屏，确认画面中没有可见轨迹线或拖尾。
- **核心复现流程：**关于我 → 我的作品 → 打开作品内容 → 关闭 → 我的世界 → 打开世界内容 → 关闭 → 关于我，连续循环至少三轮；每轮旧片回到其编号原位、目标片正确落盘，无机身前缘或机盖穿模。
- **状态稳定：**分别用关闭按钮、Esc、点背景返回后换片；快速点多个入口；点当前入口；换片后重播再换片。确认没有唱片跳位、重复实例、残留动画或缩放漂移。
- **比较证据：**同一视口下比较进入内容前与关闭后的世界姿态；所有 stored 唱片应匹配当前布局的展示锚点，on-player 唱片应匹配唱盘锚点。取换片关键帧检查完整物体间隙，不以第一次能播放动画作为验收通过。
