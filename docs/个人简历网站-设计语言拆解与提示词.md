## 一、逐作品拆解

### ① Yanni Xing · 3D 办公桌

| 维度 | 特征 |
|---|---|
| 设计语言 | 低多边形（low-poly）3D 场景 + 拟物隐喻 + IP 彩蛋叙事（The Office / Dunder Mifflin） |
| 窗口风格 | 场景层没有传统网页 UI；点击显示器后进入复古 macOS（System 9 式条纹标题栏）桌面，窗口才出现 |
| 构图 | 单主角居中构图：桌子占画面约 60%，3/4 俯视等距视角；背景近纯白（#F2F2F2），留白极大；底部仅一行人名 "YANG XING" + 一行提示语 |
| 材质 | 无纹理平涂（flat shading）：灰蓝桌面、白/银色 Apple 设备、米色椅子、暖色点缀（Dunder Mifflin 蓝、金色奖杯）；柔和环境光遮蔽阴影，无镜面反射 |
| 文字 | 大写、宽字距（letter-spacing 0.2em+）、极小号无衬线/等宽字体；文字刻意低调，让 3D 物件当主角 |
| 交互与衔接 | 物件=入口：点击显示器→相机推近（zoom-in）→"进入"电脑桌面；打印机出纸、抽屉抽拉、椅子旋转都是 micro-interaction 反馈，不承载导航，只承担"性格" |
| 素材设置 | Blender 建低模 → glTF 导出 → three.js 渲染；每个物件独立 mesh + Raycaster 点击检测；相机运动用 GSAP tween；文字用 HTML overlay 叠在 canvas 上 |

### ② cici · 复古窗口 + 拼贴

| 维度 | 特征 |
|---|---|
| 设计语言 | retro-OS 拟物（Windows 9x / 老 Mac 混血）+ 手工剪贴拼贴 + 幽默人格化 |
| 窗口风格 | 经典 9x 窗口：浅灰浮雕立体边框、条纹滚动条、右侧 — □ × 三键、标题栏居中 "nothingbutcici"；整个网页被装进一个"浏览器窗口"里，窗外是壁纸 |
| 构图 | 满屏壁纸（上半：巧克力棕+米色竖条纹；下半：深棕波点墙裙）→ 中央一个大窗口（约 70% 宽）→ 窗口内左右分区：左侧特大号标题 "nothing but cici." + 一行 4 个拟物文件夹；右侧人物抠像头像 + 3 张歪贴便签（Claude Code / Marketing Engineer / Codex） |
| 材质 | 纸感噪点底纹、便签纸微投影、贴纸感标签、牛皮纸色拟物文件夹、CSS 图案（条纹/波点）代替贴图 |
| 文字 | 展示层：几何粗黑无衬线（"cici." 极大、句点收尾）；辅助层：小号衬线体；便签用微倾斜手写感 |
| 页面衔接 | **全程不跳转**：顶部导航和文件夹都是锚点 → 平滑滚动（smooth scroll）到页面下方的对应 section；窗口是"外壳"，内容在窗口内向下延展 |
| 素材设置 | 人物抠像 PNG（1-2 张，循环小动画）、便签/贴纸 SVG、拟物文件夹 SVG、壁纸用 CSS background-image 渐变条纹 + radial-gradient 波点，几乎零图片依赖 |

### ③ pocketfolio · 掌机设备

| 维度 | 特征 |
|---|---|
| 设计语言 | 设备隐喻（电子宠物机/Tamagotchi 掌机）+ "小屏幕大想法"的约束叙事 |
| 窗口风格 | 没有"窗口"，整台设备就是浏览器视口：粉色塑料外壳、内嵌小屏幕、实体感按键（A / B / NEXT）、摇杆点 |
| 构图 | 设备居中占 70%；屏幕外是说明区："How to play"（操作说明做成 onboarding 内容）、侧边任务 side quest、章节标签（Work / About me / My practice / Background） |

| 页面衔接 | 不跳转：内容在"屏幕内"翻页/滚动，按键驱动状态机（NEXT → 下一屏）；章节标签直接把屏幕内容切到对应页 |
| 素材设置 | 设备外壳一张（CSS/绘图均可，带按键分层）、屏内内容全部组件化、按键音效可选、像素图标 |

## 二、三个作品共同的设计规律（最重要）

1. **隐喻先行**：先选一个空间/物件系统（办公桌 / 操作系统 / 掌机），全站所有 UI 服从这个隐喻，不混入现代 SaaS 组件。
2. **内容切成物件**：简历的每个章节 = 一个可点击物件（文件夹 / 图标 / 按键），导航即探索。
3. **微交互承担性格**：出纸、抽拉、吹泡泡糖、按键音——这些"无用但可爱"的反馈才是记忆点。
4. **衔接发生在隐喻内部**：进屏幕、向下滚、翻页，都伪装成"在设备里操作"，而不是网页跳转。
5. **文字极度克制**：每屏一句话 + 少量标签，大字号只给名字/主张。
6. **低素材依赖**：主要靠 CSS/SVG/几何绘制，照片级素材只有 1-2 张（人物抠像）。

## 三、可复用提示词

### 提示词 A · 复古 OS 窗口风格（对应参考②，落地成本最低）

```
设计并实现一个个人简历网站单页，整体是一台"复古操作系统"：

【整体风格】90 年代复古拟物 OS（Windows 9x 与经典 Mac 混血）+ 手工拼贴感，
温暖纸感，幽默、有人格；禁止现代扁平 SaaS 风格、禁止渐变玻璃拟态。

【背景】全屏壁纸：上半部分为巧克力棕与米色相间的垂直宽条纹，
下半部分为深棕色底 + 奶白色大波点（CSS 渐变实现，不用图片）。

【主窗口】视口中央一个约 70% 宽的复古窗口：
- 浅灰立体浮雕边框（outset 边框 + 1px 高光/阴影线）
- 标题栏居中显示 "xxx.github.io"，右侧 — □ × 三个经典按钮
- 窗口内容底色米白 #F5F2EA，带极轻纸纹噪点

【首屏内容】窗口内左右分区：
- 左侧：小字 "nothing but" + 超大几何粗黑标题（名字 + 句点），
  下方一行 4 个拟物文件夹图标（牛皮纸色，SVG 绘制），
  分别为 About me / Projects / Skills / Contact
- 右侧：一张人物抠像照片 + 2~3 张微倾斜彩色便签贴纸
  （写上身份关键词，如 "Data Engineer" "LLM Agent"），
  便签带小投影，像手工贴上去的

【交互】不使用页面跳转：点击导航或文件夹 → window.scrollTo 平滑滚动
到对应章节；每个章节仍是同一窗口的向下延续；
滚动条样式化为复古条纹滚动条。

【微交互】文件夹 hover 时轻微上浮 + 阴影加深；便签 hover 轻微摆动；
可加一个"垃圾桶"图标，点击弹出怀旧提示气泡。

【字体】标题用几何粗黑无衬线（中文可用 Noto Sans SC Black，英文可配
Archivo Black / Space Grotesk）；正文小号衬线；文件名用等宽字体。

【技术】纯 HTML/CSS/JS（或 React），全部图形用 CSS/SVG，不依赖图片素材。
```

### 提示词 B · 3D 低模工作台风格（对应参考①，视觉冲击最强）

```
设计并实现一个 3D 交互个人简历网站，主体是一个可探索的低多边形工作台：

【场景】浅灰白纯色背景（#F2F2F2），画面中央一张 3/4 等距视角的深灰蓝
办公桌，桌上摆放：显示器（屏幕亮着，显示终端/主页）、键盘、鼠标、
马克杯、文件托盘、笔记本、打印机、小盆栽；桌下三抽屉柜 + 一把米色
办公椅。全部低多边形平涂材质，无纹理贴图，柔和阴影。

【入场】加载后相机从远处缓缓推近到默认机位；页面底部居中显示
大写宽字距的名字 + 一行提示 "Click the screen to enter"。

【交互】
- 鼠标拖动：围绕桌子旋转（限制俯仰角）
- 滚轮：拉近拉远（限制距离范围）
- hover 物件：轻微高亮 + 光标变 pointer + 浮出名称标签
- 点击物件：各自播放一个小动画（打印机出一张纸、抽屉抽拉、
  椅子旋转一圈、马克杯冒热气）
- 点击显示器：相机推近屏幕直至充满视口 → 淡出进入"桌面内容层"

【桌面内容层】进入后是一套复古 macOS 风格桌面（条纹标题栏、
拟物文件夹图标：about.md / projects / skills / resume.pdf），
点击桌面图标打开窗口浏览项目详情；提供"返回场景"按钮退回 3D 视角。

【文字】3D 场景内文字极少：仅名字与提示语，大写、字距 0.25em、
等宽或细无衬线；内容都在桌面层的窗口里。

【技术】three.js（或 React Three Fiber）+ GSAP 相机 tween +
Raycaster 点击；模型用 Blender 低模导出 glTF，单文件 < 3MB，
移动端降级为静态渲染图 + 点击热点列表。
```

### 提示词 C · 掌机设备风格（对应参考③，最有梗）

```
设计并实现一个"装在掌机里的个人简历"网站：

【整体】页面背景为柔和纯色；中央一台竖向粉色复古掌机（电子宠物机
比例），占视口高度约 80%；外壳用 CSS 渐变做塑料高光与倒角，
带内嵌屏幕、十字键、A / B 两个圆形按键和一个 NEXT 长条按键。

【屏幕】屏幕即内容视口（约 4:3，圆角、轻微内阴影 + 扫描线质感）：
- 开机动画：像素 logo 闪烁 → 进入首页
- 首页显示名字 + 一句话身份 + 4 个像素风章节图标
  （Work / About me / Skills / Contact）

【交互（状态机，不跳转）】
- NEXT 或 A 键 → 屏幕内容切到下一章节，带老式滑动/闪烁转场
- 十字键上下 → 屏幕内滚动长内容
- 屏幕外的实体按键均映射同样操作（点击/键盘快捷键均可）
- 设备旁放置 "How to play" 说明书卡：用幽默文案解释操作方式，
  把 onboarding 做成内容的一部分

【文字】屏幕内像素/等宽字体、小字号、米白底深灰字；
屏幕外说明文字用普通无衬线，像产品说明书。

【素材】外壳与按键全部 CSS/SVG 绘制；屏内图标用 8-bit 风格 SVG；
可选 8-bit 按键音效（默认关闭）。

【技术】纯前端实现（React 均可），核心是一个屏幕内容状态机，
无需任何后端。
```

### 提示词 D · 融合版（B 起步、预留 A：复古 OS 为内容层，3D 工作台为入口）

```
设计并实现一个"3D 工作台 → 复古电脑桌面"双层结构的个人简历网站：

【第一层 · 入口】3D 低模工作台（按提示词 B 的场景与交互实现），
但桌面层内容与交互按提示词 A 的复古 OS 系统实现。
点击显示器 → 相机推近 → 进入桌面。

【第二层 · 内容】复古 OS 桌面（按提示词 A 的窗口风格）：
桌面图标 = about.md / projects / skills / contact；
双击打开复古窗口，窗口内向下滚动浏览；
项目详情统一为"问题 → 做法 → 结果 + 一段真实终端运行日志"的卡片结构。

【关键约束】
- 两层共用同一套设计 token：米白纸感底 #F5F2EA、石墨窗口条 #2A2927、
  强调蓝 #2F5BFF、终端绿 #6BE08A
- 3D 场景里的每件物品与桌面的文件夹一一对应（显示器=项目总览、
  文件托盘=文章、抽屉=实验记录、椅子=关于我）
- 全站无生硬路由跳转：所有转场都发生在隐喻内部
  （推近屏幕 / 窗口内滚动 / 开关窗口）

【阶段策略】v1 先上线第二层（纯 DOM 的复古桌面，成本最低），
3D 入口作为 v2 替换首页，内容层零改动。
```

## 四、素材清单模板（做之前先备齐）

| 类别 | 参考①Yanni | 参考②cici | 参考③pocketfolio |
|---|---|---|---|
| 人物素材 | 无 | 抠像头像 PNG ×1-2 | 无（可用像素头像） |
| 环境素材 | Blender 低模（桌/椅/设备/杂物，约 10-15 个 mesh） | 无（壁纸全 CSS） | 设备外壳（CSS/SVG 绘制） |
| 图标 | 贴图（屏幕内容） | 拟物文件夹/便签 SVG ×6-8 | 像素图标 ×4-6 |
| 字体 | 宽字距等宽 ×1 | 黑体展示 + 衬线正文 ×2 | 像素/等宽 ×1 |
| 音效 | 可选 | 无 | 8-bit 按键音 ×2（可选） |
| 技术依赖 | three.js + GSAP | 零依赖 | 零依赖 |
